# Adventure Works — Sales Analytics Project

## 📌 Project Overview
End-to-end sales data analysis on Microsoft's AdventureWorks 
dataset for a fictitious multinational bicycle manufacturing 
company. Analyzed 3 years of sales data across multiple 
regions, products, and customers.

## 🛠 Tools Used
- MySQL — Data extraction, KPI queries & performance analysis
- Excel  — Data cleaning, Pivot Tables & dashboard creation
- Power BI — Interactive dashboard with drill-downs & filters

## 📊 Key Results
- 29.36M total sales calculated across all regions
- 12.08M total profit analyzed
- 18,000+ customers segmented by purchase value
- Top 10 products & regions identified by sales & profit
- Sales trends analyzed across 2010–2014
- Regional performance compared across 6 territories

## 🗄 SQL Queries Covered
- Database & table creation
- Data cleaning & column additions
- Date extraction (Year, Month, Quarter, Financial Quarter)
- KPI calculations (Sales, Profit, Avg Order Value)
- Top 10 products by sales & profit
- Region-wise & country-wise performance
- Customer performance analysis
